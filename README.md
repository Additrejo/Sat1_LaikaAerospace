# Sat1_LaikaAerospace 2023
<img width="609" height="441" alt="image" src="https://github.com/user-attachments/assets/207c28ae-18f6-47c3-9454-d26cb2ab9888" />  

Este proyecto consiste en el desarrollo de un picosatélite experimental diseñado por el equipo de Carga Útil del grupo Laika Aerospace, dedicado a cohetería experimental. Su objetivo principal es medir y registrar datos atmosféricos y de vuelo durante el lanzamiento, integrando tecnologías como sensores ambientales, comunicación inalámbrica y procesamiento de datos.

El picosatélite sirve como una plataforma educativa para la aplicación de conceptos de electrónica, programación y sistemas espaciales, contribuyendo al aprendizaje práctico dentro del sector aeroespacial experimental, así como para competencias de cohetería.
